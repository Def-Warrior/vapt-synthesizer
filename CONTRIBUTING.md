## 🌟 Hacktoberfest 2026 Directives

This project implements the **Agent Skill Open Standard v2** (`SKILL.md`) and is designed to operate 100% locally with zero off-host telemetry.

We warmly welcome pull requests from developers of all skill levels!

### 🎯 Good First Issues & Feature Roadmap

If you are looking for an issue to claim for Hacktoberfest, check out these recommended tasks:

1. **[Good First Issue #1] Additional Log Parsers:**
   - **Nessus Parser:** Create `agent/parsers/nessus.py` to ingest `.nessus` XML reports.
   - **Nuclei Parser:** Add ingestion for JSONL finding streams generated by ProjectDiscovery's Nuclei.
   - **Nikto Web Scanner:** Parse text/CSV/XML output from Nikto web scans.
2. **[Good First Issue #2] Multimodal Enhancement:**
   - Add automated Optical Character Recognition (OCR) fallback for visual network diagrams.
3. **[Good First Issue #3] Report Localization:**
   - Add multilingual templates for the Executive Audit Dossier (e.g. Spanish, German, French, Urdu).
4. **[Good First Issue #4] Additional Unit Tests:**
   - Expand `tests/` coverage for edge-case corrupted XML feeds and IPv6 topology structures.

## 🛠️ Local Development & Setup

1. **Fork & Clone:**
   ```bash
   git clone https://github.com/your-username/vapt-synthesizer.git
   cd vapt-synthesizer
   ```

2. **Set up Python Virtual Environment:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. **Install Ollama & Gemma 4:**
   ```bash
   ollama pull gemma4
   ```

4. **Run Automated Test Suite:**
   All contributions must pass the test suite before merging:
   ```bash
   pytest -v
   ```

5. **Start Application Locally:**
   ```bash
   streamlit run app.py
   ```

## 📋 Pull Request Guidelines

1. **Branch Naming:** Use clear branch names such as `feature/nuclei-parser` or `fix/xml-sanitization`.
2. **Test Coverage:** Add a corresponding unit test in `tests/test_*.py` for any new parser or engine feature.
3. **Keep Air-Gap Integrity:** Never introduce cloud API keys, external CDNs, or tracking scripts. Everything must run on-device.
4. **Code Quality:** Ensure formatting adheres to PEP 8 standards.
