# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

The **Agentic VAPT Synthesizer** is built for high-security, air-gapped environments. We take vulnerabilities and telemetry leaks extremely seriously.

If you discover a security flaw (such as XML External Entity injection vulnerabilities in the parser, authentication bypasses, or unexpected outbound telemetry):

1. **Do not** disclose the issue publicly in GitHub Issues or Discussions.
2. Email the core security team at `security@vapt-synthesizer.local` with the subject `[SECURITY VULNERABILITY] VAPT Synthesizer`.
3. Provide reproduction steps, minimal sample payload, and potential remediation.

We aim to acknowledge reports within 24 hours and patch critical exposures promptly.
